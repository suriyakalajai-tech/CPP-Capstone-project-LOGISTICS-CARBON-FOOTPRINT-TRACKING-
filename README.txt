LOGIFLOW FRONTEND
==================
A frontend prototype for the C++ Logistics & Supply Chain Carbon Footprint Tracking System.

Reference design:
- The visual language is based on the supplied Jal Rakshak frontend: dark command-center UI,
  Orbitron/Poppins typography, cyan/blue accents, rounded cards, sidebar dashboard,
  responsive layouts, theme toggle, and localStorage-based frontend persistence.

Project focus:
- Module 1: Carbon Engine + Route Optimization
- Module 2: Shipment Management / CRUD + persistence concept
- Road / Rail / Sea / Air
- C = alpha * Time + beta * CO2

Files:
- index.html      Shipment Management (Module 2)
- dashboard.html  Carbon Command (Module 1)

Important:
The emission factors and speed values in dashboard.html are explicitly FRONTEND DEMO PLACEHOLDERS.
Replace them with the actual emission-factor dataset and route data used by the C++ implementation
before presenting calculated results as project results.
